# Mansur AI

ИИ-платформа: сайт с бесплатными нейросетями и Windows-приложение — ИИ-агент, который сам выполняет задачи на компьютере.

## Как запустить

1. Дважды щёлкните **`start-site.bat`**. Откроется окно сервера и браузер с адресом http://localhost:8000. Пока окно открыто, сайт работает.
2. Войдите или зарегистрируйтесь. Аккаунт администратора: `admin@mansur.ai` / `admin12345` — **смените пароль в профиле** (без этого сайт не опубликуется в интернет, см. DEPLOY.md).
3. Windows-приложение: на главной странице сайта кнопка **«Скачать для Windows»** → установите `MansurAI-Setup.exe` → войдите тем же аккаунтом.
4. Чтобы остановить базу данных — `stop-site.bat`.

Документация API (Swagger): http://localhost:8000/docs

## Что внутри

| Папка | Что это |
|---|---|
| `server/` | Laravel 13 (PHP 8.4): REST API + сайт |
| `server/app/Services/` | Бизнес-логика: `MessageService` (сценарий 1, лимиты), `AgentTaskService` (сценарий 2, статусы), `AiGateway` (нейросети) |
| `server/public/js/app.js` | Сайт (чат, задачи, админ-панель) |
| `server/tests/Feature/` | Автотесты сценариев (`php artisan test`) |
| `desktop/` | Windows-приложение (Electron): `agent.js` — цикл агента, `tools.js` — инструменты |
| `runtime/` | PHP-настройки, база PostgreSQL (порт 5433), Composer |

## Нейросети

Работают **сразу, без ключей** (сервис Pollinations):
- **Mansur Chat** — универсальный помощник (GPT-OSS 20B);
- **Mansur Coder** — помощник программиста;
- **Mansur Image** — генерация изображений;
- **Mansur Agent** — модель для Windows-агента.

⚠ Без ключа Pollinations даёт **1 ответ и 1 картинку в 45 секунд на весь сервер**. Если модель занята, сервер через 12 секунд передаёт вопрос запасной модели (OpenRouter), поэтому пользователь всё равно получает ответ.

Через OpenRouter (ключ уже добавлен) работают: «Авто», Nemotron 3 Ultra, Nemotron 3.5 Super, ERNIE 5.5 Flash, North Mini Code.

Каждая модель проверена живым вопросом («17×23 и что такое HTTP»):

- добавлены **ERNIE 5.5 Flash** (ответ за 1,5 с, умеет вызывать инструменты, стала и запасной моделью агента) и **Nemotron 3.5 Super**;

Повторить проверку: Админ-панель → «Провайдеры» → «✓ Проверить модели».

### Как добавить бесплатные нейросети (Gemini, Groq, Mistral…)

Админ-панель → вкладка **«Провайдеры»** → у нужного провайдера «🔑 Получить ключ» → зарегистрируйтесь, создайте ключ → вставьте → «Сохранить» → «✓ Проверить модели». Модели сразу появятся у всех пользователей. Кнопка «＋ Импорт моделей» загружает актуальный список моделей прямо у провайдера.

| Провайдер | Где взять ключ | Что даёт |
|---|---|---|
| Google Gemini | https://aistudio.google.com/apikey | Gemini Flash / Flash-Lite, быстрый агент |
| Groq | https://console.groq.com/keys | GPT-OSS 120B/20B, очень быстрые ответы, агент |
| OpenRouter | https://openrouter.ai/keys | Десятки бесплатных моделей (`:free`) |
| Mistral AI | https://console.mistral.ai/api-keys | Mistral Small / Medium |
| Cerebras | https://cloud.cerebras.ai | Сверхбыстрые открытые модели, агент |
| Pollinations | https://enter.pollinations.ai | Снимает лимит 1 ответ / 45 с |

Ключи хранятся в базе в зашифрованном виде и никогда не передаются пользователям. Можно и по-старому — вписать в `server/.env`.

### Правила безопасности

Включены по умолчанию (`AI_MODERATION=true` в `.env`):
- запросы с матом и контентом 18+ отклоняются до отправки нейросети (код — `app/Services/ContentFilter.php`);
- для картинок фильтр строже (нагота, бельё и т. п.) + у генератора включён безопасный режим;
- каждая нейросеть получает инструкцию не ругаться и не создавать взрослый контент;
- если мат всё же попал в ответ, он заменяется звёздочками.

## Сборка приложения

`build-app.bat` — соберёт установщик и положит его в `server/public/downloads/`, откуда его скачивают с сайта.
Запуск приложения без установки (для разработки): `run-app-dev.bat`.

## Публикация в интернете

Сейчас всё работает локально (`php artisan serve` — однопоточный сервер для разработки). Для реального сайта нужны VPS (Nginx + PHP-FPM + PostgreSQL), домен и HTTPS. В `server/.env` поменяйте `APP_URL`, `APP_ENV=production`, `APP_DEBUG=false`, а в приложении — адрес сервера (Настройки → «Адрес сервера», или значение `server` в `desktop/main.js` перед сборкой).

## Вход через Google, GitHub и Apple

Админ-панель → вкладка **«Вход через соцсети»**. Для каждого сервиса:
1. Нажмите «🔑 Открыть консоль» и создайте OAuth-приложение.
2. Скопируйте из карточки **адрес перенаправления (callback)** и вставьте его в настройки приложения в консоли.
3. Вставьте Client ID и Client secret (для Apple ещё Team ID, Key ID и ключ .p8) и нажмите «Сохранить».

Кнопки сразу появятся в окне входа и регистрации на сайте и в Windows-приложении. Приложение открывает вход в обычном браузере и принимает ответ на `127.0.0.1`. Если email уже зарегистрирован, вход через соцсеть привязывается к этому аккаунту. Пароль для входа по email можно задать в профиле.

⚠ **Apple** работает только с платным Apple Developer ($99/год) и на настоящем домене с HTTPS — с `localhost` Apple не принимает. Google и GitHub работают и на `http://localhost:8000`.

## Команда агентов (платная услуга)

Первый агент (**Мансур**) бесплатный. Остальных пользователь покупает по одному, покупка разовая:

| № | Агент | Цена |
|---|---|---|
| 1 | Мансур — базовый агент | бесплатно |
| 2 | Барыс — снежный барс | 3 000 ₸ |
| 3 | Тулпар — крылатый конь | 4 000 ₸ |
| 4 | Беркут — золотой орёл | 5 000 ₸ |
| 5 | Самрук — легендарная птица | 6 000 ₸ |

Каждый агент выполняет свою задачу, поэтому при N агентах Windows-приложение делает N задач одновременно. Сервер не даст запустить больше задач, чем куплено агентов. Персонажи — 3D-модели (three.js) в `server/public/js/agents3d.js`: на главной, на странице «Команда агентов» и в окне покупки их можно крутить мышкой. Из этих же моделей отрендерены картинки `server/public/img/agents/*.png` для мелких мест. Купленные агенты видны в правом нижнем углу на всех страницах сайта и приложения. Цены и описания заданы в `server/config/agents.php`.

**Режим «Вместе»** (от 2 агентов): галочка «Вместе» при создании задачи. Главный агент делит задачу на части, остальные агенты делают их одновременно в одной папке, затем главный проверяет и собирает проект целиком.

Сейчас включена **демо-оплата** (`AGENT_PAYMENT_MODE=demo` в `.env`): агент добавляется сразу, деньги не списываются. Чтобы закрыть покупку, укажите `AGENT_PAYMENT_MODE=off`. Настоящая оплата (Kaspi Pay, CloudPayments и т. п.) требует договора с платёжным сервисом. Администратор может подарить или забрать агентов в админ-панели (вкладка «Пользователи», колонка «Агенты»), а выручку видно на вкладке «Статистика».
