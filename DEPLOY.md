# Mansur AI в интернете

## Вариант 1. С этого компьютера (бесплатно, сразу)

1. Войдите на сайт администратором и **смените пароль** в профиле: со стандартным `admin12345` публикация не запустится.
2. Запустите `publish-site.bat` из папки проекта.
3. Скрипт:
   - включит режим для интернета (без отладки);
   - проверит безопасность;
   - запустит 4 обработчика сайта и распределитель нагрузки;
   - откроет туннель Cloudflare.
4. В окне появится адрес вида `https://….trycloudflare.com`. Он уже скопирован, отправляйте его людям.
5. Сайт работает, пока открыто окно и включён компьютер. Нажмите Enter в окне, чтобы снять сайт с публикации.

Ограничения:
- при каждом запуске адрес новый;
- вход через Google и GitHub работает только с тем адресом, который записан в их консолях;
- в Windows-приложении нужно вписать адрес в поле «Адрес сервера».

## Вариант 2. Свой сервер VPS (постоянно, с доменом)

Понадобится:
- VPS с Ubuntu 24.04, 2 ГБ памяти, примерно 2500–5000 ₸ в месяц (PS.kz, Hoster.kz или любой другой);
- домен, например `mansur.kz`, примерно 5000 ₸ в год.

1. **Домен.** У регистратора добавьте A-запись: домен → IP-адрес сервера.
2. **Перенос базы (по желанию).** Чтобы сохранить пользователей, чаты и покупки, выполните на этом компьютере:
   ```
   C:\OSPanel\modules\PostgreSQL-17\bin\pg_dump.exe -h 127.0.0.1 -p 5433 -U postgres -Fc mansur_ai -f deploy\mansur_ai.dump
   ```
   Без этого шага на сервере будет новая пустая база с администратором.
3. **Загрузка проекта.** Скопируйте папку проекта на сервер в `/var/www/mansur-ai`, например программой WinSCP. Папки `server/vendor`, `desktop/node_modules`, `runtime/pgdata` копировать не нужно.
4. **Установка.** На сервере по SSH выполните:
   ```
   bash /var/www/mansur-ai/deploy/setup.sh mansur.kz ваш@email
   ```
   Скрипт сам установит nginx, PHP 8.4, PostgreSQL 17 и HTTPS-сертификат, настроит брандмауэр и ежедневные резервные копии базы. В конце он покажет адрес сайта и, если база новая, пароль администратора.
5. **Вход через Google и GitHub.** В консолях Google и GitHub добавьте новые адреса перенаправления (Админ-панель → Вход через соцсети покажет их):
   - `https://mansur.kz/auth/google/callback`
   - `https://mansur.kz/auth/github/callback`

   После этого вход через Apple тоже можно настроить: на домене с HTTPS он работает.
6. **Приложение для Windows.** На этом компьютере выполните `build-app.bat https://mansur.kz`. Установщик будет подключаться к вашему сайту, загрузите его в `server/public/downloads/` на сервере.
7. **Почта для «Забыли пароль?».** В Админ-панели откройте вкладку «Почта», введите данные Gmail и пароль приложения, затем нажмите «Отправить тест».

## Что уже сделано для безопасности

- Пароли хранятся только в виде хеша. Ключи нейросетей, OAuth и почты зашифрованы и не отдаются в браузер.
- Вход, регистрация и сброс пароля: не больше 10 попыток в минуту с одного IP. API: 60 запросов в минуту.
- Заголовки защиты: от встраивания сайта в чужие страницы, от подмены типов файлов и от утечки адреса. На HTTPS включён HSTS.
- Проверка `php artisan mansur:check-public` не даёт открыть сайт со стандартным паролем администратора или с включённой отладкой.
- Есть страница политики конфиденциальности `/privacy`: она нужна для публикации входа через Google.
- На VPS: брандмауэр открывает только SSH и веб, база копируется каждый день, копии хранятся 14 дней.
